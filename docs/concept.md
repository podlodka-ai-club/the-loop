# Loci

## Название

`Loci` — множественное число латинского слова `locus`, «место». Название отражает задачу
агента: находить место съёмки и накапливать знания о характерных признаках разных мест.

## Назначение

Loci — фоновый агент геолокации по фотографии. Он предназначен для определения наиболее
вероятного места съёмки, когда точные координаты и надёжные метаданные недоступны.

## Как работает

Агент изучает видимые признаки: ландшафт, климат, растительность, архитектуру, дорожную
инфраструктуру, транспорт, язык и другие локальные особенности. На их основе он формирует
кандидатов, выбирает наиболее вероятное место и кратко объясняет вывод.

Production, обучение и оценка памяти используют один [слепой цикл
геолокации](/workflows/locate.md), чтобы сравнивать одно и то же поведение решателя.

## Инференс

[Production-инференс](/workflows/inference.md) принимает пользовательскую фотографию, проверяет
вход и закрепляет активный snapshot памяти. Общий solver анализирует изображение, при необходимости
несколько раз запрашивает память, разрешает названия через геокодер и возвращает наиболее вероятное
место, альтернативы, краткое объяснение и ограничения.

Inference не получает ground truth и не изменяет память.

## Обучение

[Обучение](/workflows/train.md) последовательно проходит train-корпус. Для каждого примера агент
сначала решает задачу с текущим snapshot памяти. Ответ и все обращения к памяти фиксируются, после
чего агент получает ground truth и выполняет рефлексию.

Результатом рефлексии становятся короткие заметки для будущих задач.
[`memory_store`](/tools/memory_store.md) добавляет их к текущей памяти и создаёт новый immutable
snapshot, который используется на следующем примере. Внутри обучения нет baseline-run и общего
score.

## Оценка

[Оценка памяти](/workflows/evaluate.md) выполняется отдельно от обучения на независимом
eval-корпусе. Сначала весь корпус проходит inference без памяти и даёт `baseline_score`. Затем тот
же корпус с той же runner-конфигурацией проходит с выбранным snapshot и даёт `memory_score`.

Разница между scores показывает эффект памяти. Во время обоих прогонов ground truth раскрывается
только scorer после фиксации ответа, а память не изменяется.

## Память

Память Loci — внешнее хранилище текстовых заметок, организованное в неизменяемые snapshots. Во
время решения агент получает релевантные заметки через
[`memory_retrieve`](/tools/memory_retrieve.md).

Извлечённые заметки используются как подсказки, а не как факты: агент сопоставляет их с текущей
фотографией. Production и evaluation только читают память; новые snapshots создаются исключительно
в training-контуре после reveal.
