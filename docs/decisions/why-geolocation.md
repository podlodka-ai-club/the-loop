**Решение принято.** Первым доменом Loci выбрана [геолокация по уличному фото](/domain/geolocation-task.md).

# Критерии отбора

Домен оценивался по шести осям; провал любой делает замер прогресса невозможным.

| Критерий | Требование |
|---|---|
| Грейдер | Программа, не модель-судья: шум LLM-судьи того же порядка, что ловимый эффект |
| Метрика | Непрерывная, см. [обоснование](/decisions/why-continuous-metric.md) |
| Запас по потолку | Baseline не у пола и не у потолка, иначе расти нечему или сигнала нет |
| Переносимость опыта | Между задачами есть общая структура, иначе накапливать нечего |
| Отсутствие утечки | Ответ не может быть извлечён из памяти модели |
| Скорость | Задача укладывается в секунды-минуты: за хакатон нужны сотни задач, иначе кривая из трёх точек |

# Почему геолокация проходит по всем

- **Грейдер** — расстояние между двумя парами координат, чистая функция.
- **Метрика** непрерывна по своей природе.
- **Утечки нет по построению**: координаты конкретного краудсорсингового кадра модель запомнить не могла, она может только выводить их из признаков. Это отличает домен от любого публичного корпуса.
- **Опыт переносим**: признаки местности работают на невиданных кадрах.
- **Не решается солвером** — знание накапливается только опытом.
- **Данные** бесплатны, бесконечны и с точной истиной прямо в API — см. [Mapillary](/data/mapillary.md).

# Дополнительные соображения

**Опыт сам по себе является демонстрацией.** [Накопленная мета](/domain/learned-meta.md) читается человеком как заметки эксперта — судья открывает базу знаний и видит результат обучения, а не верит графику на слово. Ни один другой рассмотренный домен не даёт этого в такой степени.

**Естественная нарезка страт.** Разделение held-out по странам осмысленно и легко реализуемо, что даёт честную проверку обобщения.

# Известная слабость

Baseline у фронтир-модели в геолокации не нулевой — какое-то умение есть и без опыта. Потолок при этом остаётся большим. Мера — [контрольный прогон с выключенной памятью](/evaluation/ablation-controls.md), честно показывающий вклад накопленного опыта. Дополнительный вариант — вынести решение задач на слабую локальную модель, см. [роли моделей](/decisions/model-roles.md).
