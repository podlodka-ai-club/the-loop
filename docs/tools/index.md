# Инструменты Loci

Каталог описывает контракты всех инструментов, доступных агенту Loci. По мере развития workflow
сюда добавляются новые инструменты, их назначение, входы, выходы, ограничения и обработка ошибок.

| Инструмент | Назначение |
|---|---|
| [`memory_retrieve`](memory_retrieve.md) | Получить релевантные заметки из выбранной системы памяти. |
| [`memory_store`](memory_store.md) | Добавить обучающие заметки в выбранную систему памяти. |
| [`geocode_search`](geocode_search.md) | Найти объекты по названию или адресу. |
| [`geocode_reverse`](geocode_reverse.md) | Получить ближайший объект и address components по координатам. |
