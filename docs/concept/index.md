# Project

# Mechanism

* [Маховик опыта](experience-flywheel.md) - Цикл из четырёх шагов, превращающий результат каждой задачи в переиспользуемый опыт.
* [Три уровня памяти](memory-tiers.md) - Разделение накопленного опыта на эпизодический, семантический и процедурный слои.
* [Ретривал опыта](retrieval.md) - Как из накопленной памяти отбирается то немногое, что подаётся агенту под конкретную задачу.

# Schema

* [Карточка урока](lesson-card.md) - Единица накопленного опыта: структура полей, жизненный цикл и правила отбраковки.
