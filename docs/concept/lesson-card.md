# Схема

| Поле | Назначение |
|---|---|
| `trigger` | Структурированные признаки задачи, при которых урок применим. Основа [ретривала](/concept/retrieval.md) — фильтрация идёт по этому полю, а не по эмбеддингу целиком |
| `claim` | Что делать или чего избегать |
| `evidence` | Список `task_id`, на которых урок родился и подтверждался |
| `score` | Счётчики применений: wins, losses, confidence |
| `status` | `probation` → `active` → `retired` |
| `savings` | Сколько шагов или токенов экономит применение |

# Пример для домена геолокации

```yaml
trigger:
  road_markings: yellow_center
  driving_side: right
claim: >
  Жёлтая разметка по центру при правостороннем движении сужает выбор до
  Северной Америки и Скандинавии. Различать по форме дорожных знаков,
  а не по растительности — растительность на этой паре даёт ложный сигнал.
evidence: [task_0142, task_0187, task_0231]
score: { wins: 7, losses: 1, confidence: 0.82 }
status: active
savings: { steps: 4 }
```

# Жизненный цикл

1. **Рождение.** Retro извлекает урок только из задачи с подтверждённым грейдером результатом. Статус — `probation`.
2. **Карантин.** В статусе `probation` урок применяется в теневом режиме: подтягивается и логируется, но его влияние отслеживается отдельно. Переход в `active` — после k подтверждений.
3. **Конкуренция.** У активного урока счёт обновляется по факту применения. Уроки с накопленным отрицательным счётом уходят в `retired`.
4. **Промоушен.** Урок с устойчивой статистикой консолидация превращает в [навык](/concept/memory-tiers.md).

# Негативные уроки

Анти-паттерны хранятся наравне с позитивными и на практике оказываются ценнее: «на кадрах этого типа не доверяй растительности», «при таком качестве снимка не пытайся определить регион, ограничься страной». Они срезают тупиковые ветви поиска, а значит прямо экономят бюджет задачи.

# Чего в карточке быть не должно

- **Фактов о конкретной задаче.** «На фото task_0142 была Осло» — не урок, а запись эпизодического слоя. Урок обязан быть применим к невиданному кадру.
- **Ответа как такового.** Урок описывает признак и вывод из него, а не координаты.
