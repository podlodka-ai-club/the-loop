# Цикл

| Шаг | Что происходит |
|---|---|
| **Solve** | Агент берёт задачу из очереди. Перед стартом [ретривал](/concept/retrieval.md) подтягивает релевантный опыт — не всю память. |
| **Grade** | Объективный автогрейдер выдаёт результат. Для геолокации — расстояние в километрах до истинной точки. |
| **Retro** | Отдельный проход сравнивает *что агент делал* с *что получилось* и выжимает [карточки уроков](/concept/lesson-card.md). |
| **Consolidate** | Раз в N задач фоновый проход мержит дубли, обобщает частные уроки, промоутит подтверждённые в навыки, отбраковывает проигравшие. |

Шаг Grade обязателен и обязан быть программным. Без внешнего объективного сигнала агент начинает коллекционировать галлюцинации вместо опыта: ретро не на чем основывать, и в память попадают правдоподобные выдумки.

# Консолидация как «сон»

Консолидация вынесена из горячего пути в отдельный фоновый проход по трём причинам:

- **Обобщение возможно только на массиве.** Урок «в Норвегии жёлтая разметка по центру» и урок «в Швеции жёлтая разметка по центру» сливаются в региональный только если видеть оба сразу.
- **Промоушен в навык требует статистики.** Урок становится [навыком](/concept/memory-tiers.md) после накопления подтверждений, а не по факту одного успеха.
- **Прунинг должен быть безопасным.** Удаление урока с плохим счётом — операция, которую нельзя делать в середине решения задачи.

# Бюджет на задачу

Ключевой приём, без которого кривая выходит плоской: **жёсткий лимит действий на задачу** (например, фиксированное число вызовов инструментов; при превышении задача засчитывается по текущему ответу).

Без бюджета опытный и неопытный агент оба доходят до ответа, просто разной ценой — качество почти не меняется, растёт только эффективность. С бюджетом накопленный опыт **напрямую конвертируется в качество**: сэкономленные на поиске шаги уходят в уточнение ответа. Точность и стоимость становятся одной историей, и на графике появляется читаемая ступенька.

# Защита от отравления памяти

Урок, извлечённый из случайно удачного результата, отравляет всю дальнейшую работу. Меры:

- Урок принимается только при подтверждении грейдером — не по мнению агента о том, что он молодец.
- **Карантин**: новый урок получает статус probation и применяется в теневом режиме, пока не наберёт k подтверждений (см. [карточку урока](/concept/lesson-card.md)).
- Счёт урока обновляется по факту его применения — уроки конкурируют, проигравшие уходят.
