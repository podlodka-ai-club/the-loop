# Понятие меты

«Мета» — термин сообщества GeoGuessr: накопленный свод примет, по которым место опознаётся без узнавания самого места. Живые игроки учат его годами. Для Loci это идеальный домен именно потому, что **накопленный опыт совпадает с тем, что считается мастерством у людей**, и потому читается человеком без перевода.

# Примеры формулировок уроков

> Столбики белые с красной полосой при левостороннем движении → ЮАР, не Австралия; различать по растительности.

> Жёлтая разметка по центру → Северная Америка либо Скандинавия; различать по форме дорожных знаков.

> Размытие номеров такого типа → съёмка определённого периода, что сужает регион по составу автопарка.

# Уровни знания

Мета естественно иерархична, и это влияет на структуру `trigger` в [карточке урока](/concept/lesson-card.md):

| Уровень | Пример признака | Что даёт |
|---|---|---|
| Континент | письменность, тип растительности | грубое сужение, дешёвый и надёжный сигнал |
| Страна | столбики, разметка, номерные знаки, сторона движения | основной вклад в снижение ошибки |
| Регион | конкретные сети магазинов, рельеф, тип покрытия | тонкая доводка, работает редко |

Практический вывод: **основной выигрыш в километрах даёт уровень страны**. Уроки уровня континента почти не двигают метрику (модель и без опыта редко путает континенты), уроки уровня региона срабатывают слишком редко, чтобы влиять на медиану. Ожидать роста стоит именно от страновых примет — и разбивку в отчётности имеет смысл строить по ним.

# Почему это ценно для демо

База знаний Loci к концу прогона читается как заметки эксперта. Судья открывает файл и **видит**, чему агент научился, вместо того чтобы верить графику на слово. Ни один другой рассмотренный домен этого не даёт в такой степени.
