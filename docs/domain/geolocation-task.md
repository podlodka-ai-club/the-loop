# Постановка

| | |
|---|---|
| **Вход** | Уличная фотография из [замороженного снапшота](/data/snapshot-plan.md) |
| **Выход** | Координаты предполагаемого места съёмки |
| **Грейдер** | Расстояние в километрах между ответом и истинной точкой |
| **Ограничение** | Бюджет действий на задачу (см. [маховик](/concept/experience-flywheel.md)) |

Грейдер — чистая функция от двух пар координат: детерминирован, непрерывен, не требует модели-судьи. Истина приходит из поля `computed_geometry` [Mapillary](/data/mapillary.md), точность GPS в метрах — на два-три порядка ниже масштаба нашей ошибки, поэтому шумом истины можно пренебречь.

# Почему домен подходит

- **Программный грейдер** без единого элемента субъективности.
- **Непрерывная метрика** — критично для статистической мощности, см. [обоснование](/decisions/why-continuous-metric.md).
- **Переносимый опыт.** Признаки местности работают на невиданных кадрах — в отличие от доменов, где каждая задача самобытна.
- **Нет утечки в память модели.** Координаты конкретного краудсорсингового кадра модель запомнить не могла; она может только выводить их из признаков. Это редкое свойство: у большинства публичных корпусов baseline завышен именно памятью модели.
- **Не решается солвером.** Написать программу, определяющую страну по фото, нельзя — знание накапливается только опытом. Домены с точным алгоритмом (Sokoban, минёр, Mastermind) отвергнуты именно по этому признаку, см. [отвергнутые домены](/decisions/rejected-domains.md).

# Родственные задачи

Домен принадлежит семейству «угадай по мелким уликам», у которого те же достоинства: точная истина, непрерывная ошибка, человекочитаемая мета.

| Задача | Метрика | Мета |
|---|---|---|
| Год съёмки по фото | ошибка в годах | модели машин, зерно плёнки, мода, вывески |
| Диалект или регион по тексту | точность метки | лексика, орфографические маркеры |
| Город по фото еды или меню | расстояние | шрифты, валюта, состав блюд |

Опциональное расширение: взять второй домен из этого списка и показать **перенос опыта между доменами** — агент учится не географии, а наблюдательности. Судьи такое видят нечасто, но это увеличивает объём работы и в базовый скоуп не входит.
