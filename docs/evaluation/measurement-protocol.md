# Три набора задач

Разделяются заранее и замораживаются до первого прогона.

| Набор | Объём | Назначение |
|---|---|---|
| **Train** | ~300 | Поток, на котором копится опыт |
| **Held-out A** | ~40 | Те же страны, другие кадры. Проверяет накопление |
| **Held-out B** | ~40 | **Страны, не встречавшиеся в потоке.** Проверяет обобщение, а не зубрёжку априорного распределения |

Held-out B — не формальность: без него невозможно отличить выученные признаки от выученного распределения стран в выборке, см. [ловушки](/evaluation/pitfalls.md).

# Чекпоинты

Кривая строится по замерам после 0, 25, 50, 100, 200 и 300 обработанных train-задач. На чекпоинте:

1. Память переводится в режим read-only — на held-out опыт не копится.
2. Прогоняются оба held-out набора целиком.
3. Состояние памяти фиксируется коммитом, чтобы замер был воспроизводим.

# Правило кривой

**На график идут только held-out замеры.** Текущая точность по train-потоку в отчёт не попадает: она загрязнена дрейфом сложности задач и не отделяет обучение от того, что в потоке случайно пошли простые кадры.

# Детерминизм

Один и тот же чекпоинт памяти на одном и том же held-out обязан давать один и тот же результат. Требования:

- temperature 0;
- фиксированный порядок задач;
- стабильный `task_id` у каждой задачи;
- **работа только по замороженному локальному снапшоту** — никаких обращений к API во время прогона; живой API означает недетерминизм, рейт-лимиты и риск упавшего демо;
- версия промптов и код агента зафиксированы коммитом вместе с состоянием памяти.

# Калибровка перед стартом

До того как писать движок опыта, собрать снапшот и **прогнать 20 задач голым агентом**:

| Baseline | Действие |
|---|---|
| Слишком низкий | Ослабить: увеличить долю городских кадров, поднять разрешение, смягчить бюджет |
| Слишком высокий | Ужесточить: урезать бюджет действий, добавить кадры из слабо представленных регионов |

Пока baseline не попал в рабочий коридор, движок опыта писать бессмысленно — измерять прогресс будет физически нечем. Это несколько часов работы, которые определяют, состоится ли демо.
