# Wikimedia Commons

Огромный объём геотегированных фотографий по всему миру. Основное применение — **закрыть страны, где покрытие Mapillary недостаточно для квоты**, что напрямую работает против [перекоса выборки](/evaluation/pitfalls.md).

Оговорка: кадры не уличного типа, а произвольные фотографии, поэтому смешивать их с основным потоком без разбора нельзя — характер задачи меняется. Разумнее либо держать их отдельной стратой, либо отбирать только кадры уличного вида.

# KartaView

Открытый аналог уличной съёмки. Держится как страховка: Mapillary принадлежит Meta, и сообщество уже зеркалило туда данные из опасений закрытия сервиса.

# Академические бенчмарки

Публичные наборы для задачи геолокации использовать как обучающий поток **нельзя** — они давно в открытом доступе, и baseline на них завышен памятью модели, а не накопленным опытом.

Единственное допустимое применение: прогнать по ним голого агента один раз и сравнить с опубликованными результатами, чтобы убедиться, что базовая обвязка работоспособна и агент не сломан. Это диагностика инфраструктуры, а не замер прогресса.
