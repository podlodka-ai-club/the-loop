# Что отдаёт

Эндпоинт `/images` возвращает и ссылки на кадры, и координаты съёмки.

| Поле | Назначение |
|---|---|
| `geometry` | Исходная точка съёмки |
| `computed_geometry` | Уточнённая точка — **берётся эталоном** для грейдера |
| `captured_at` | Время съёмки, Unix ms — фильтр по свежести |
| `compass_angle` | Направление камеры в градусах |
| `quality_score` | 0.0–1.0, nullable — отбраковка мусорных кадров |
| `thumb_256_url` … `thumb_2048_url` | Кадры в разных разрешениях |

Дополнительно доступны высота, параметры камеры, ориентация и данные детекций.

Поле `quality_score` закрывает [проблему мусорных кадров](/evaluation/pitfalls.md) без собственного детектора смаза — заметная экономия времени на этапе сбора.

# Доступ и стоимость

**Бесплатно.** Требуется access token из дашборда разработчика, регистрация свободная, процедуры одобрения нет.

| Лимит | Значение |
|---|---|
| Entity API | 60 000 запросов в минуту на приложение |
| Search API | 10 000 запросов в минуту на приложение |
| Тайлы | 50 000 в день |

Для проекта нужно порядка 1500 кадров — доли процента от минутного лимита, упереться невозможно.

# Ограничение bbox

Поиск по bbox работает, но **площадь запроса должна быть меньше 0.01 квадратного градуса** — примерно плитка 11×11 км. Выгрузить крупный регион одним запросом нельзя; для больших областей предлагается их Python SDK.

Для Loci это не помеха, а удобство: выборка всё равно требует [балансировки по странам](/evaluation/pitfalls.md), поэтому сбор идёт по списку городов с квотой на каждый, и страты получаются контролируемыми по построению. См. [план выгрузки](/data/snapshot-plan.md).

# Лицензия

Снимки под **CC BY-SA 4.0**. Коммерческое использование бесплатно с момента покупки Mapillary компанией Meta в 2020 году.

Два практических следствия:

- **Нужна атрибуция** — автор и ссылка. Поля автора собираются **сразу при выгрузке**: дособирать атрибуцию к готовому снапшоту крайне трудоёмко.
- **Share-alike** — публично выложенный производный датасет тоже должен быть под CC BY-SA.

Отдельно: применение изображений для обучения моделей в документации явно не оговорено. Для Loci вопрос не возникает — обучения весов нет, кадры используются для промптинга и замера, снапшот хранится локально.

# Риск

Mapillary принадлежит Meta. Сообщество уже переживало опасения закрытия сервиса: в 2020 году данные массово зеркалили в KartaView. Практический вывод — снять снапшот на раннем этапе, [KartaView](/data/alternative-sources.md) держать как запасной источник.
