# Workflows

* [Слепая геолокация Loci](locate.md) - Общий решатель одной фотографии для production, обучения и оценки.
* [Production-инференс Loci](inference.md) - Проверка пользовательской фотографии, запуск общего решателя и возврат результата.
* [Обучение Loci](train.md) - Последовательное накопление заметок в версионированной памяти после reveal.
* [Оценка памяти Loci](evaluate.md) - Два прогона одного корпуса: без памяти и с выбранным snapshot.
