# Workflows

`locate` — общее ядро: inference вызывает его один раз, training добавляет reveal и запись памяти,
а evaluation запускает его без памяти и с памятью, после чего применяет scoring.

* [Общие модели Loci](models.md) - Структуры данных, используемые несколькими workflow и tool-контрактами.
* [Слепая геолокация Loci](locate.md) - Общий workflow одной фотографии для production, обучения и оценки.
* [Production-инференс Loci](inference.md) - Проверка пользовательской фотографии, запуск общего решателя и возврат результата.
* [Обучение Loci](train.md) - Последовательная передача обучающих эпизодов в выбранную систему памяти после reveal.
* [Оценка памяти Loci](evaluate.md) - Два прогона одного корпуса: без памяти и с выбранной системой памяти.
* [Геодезический score Loci](scoring.md) - Оценка ответа по WGS84-расстоянию до ground truth.
