# Loci

Фоновый агент, который автономно обрабатывает поток задач геолокации по фотографии и с каждой итерацией становится лучше: извлекает уроки из собственных результатов, копит опыт и переиспользует его в следующих задачах.

> Loci учится узнавать места так же, как люди учатся их помнить — привязывая знание к местности.

Название — от **метода локусов**, античной мнемотехники, в которой запоминание строится через привязку к местам.

## Идея

На вход агенту подаётся уличный кадр, на выходе — координаты места съёмки. Грейдер считает расстояние в километрах до истинной точки: детерминированно, непрерывно, без модели-судьи.

Улучшается при этом не модель, а память. После каждой задачи отдельный проход сравнивает действия агента с полученной оценкой и выжимает карточки уроков; периодическая консолидация обобщает их и промоутит подтверждённые в переиспользуемые навыки.

Ключевая часть проекта — не агент-геолокатор, а **движок опыта**. Домен подключается как плагин, геолокация выбрана первой по совокупности критериев.

## Как доказывается обучение

Прогресс замеряется на замороженных held-out наборах, а не на обучающем потоке. Обязательны контрольные прогоны: память выключена, память заморожена на нулевом чекпоинте и память подменена нерелевантными уроками. Последний контроль отсекает гипотезу «лучше просто потому, что в промпте больше текста».
