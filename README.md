# Loci

Loci — фоновый агент, который определяет место съёмки по фотографии и накапливает опыт во внешней
памяти между задачами. Он возвращает координату или набор кандидатов, объясняет вывод и сохраняет
вызовы внутренних инструментов для воспроизводимой оценки.

## Как работает

Общий слепой workflow `locate` используется в трёх режимах:

- production получает ответ на пользовательскую фотографию;
- training после фиксации ответа раскрывает ground truth, формулирует полезные заметки и добавляет
  их в выбранную внешнюю систему памяти;
- evaluation сравнивает один и тот же корпус без памяти и с выбранной привязкой к системе памяти.

Память не изменяется во время inference и evaluation. Ошибки инструментов, retry и terminal failure
фиксируются в контрактах workflow, чтобы результат можно было проверить и воспроизвести.

`memory_snapshot_id` — историческое имя opaque ID привязки к системе и экземпляру памяти
(`xmemory`, Cognee, Mem0 и т.п.), а не версия данных внутри провайдера. Провайдеру не требуется
поддерживать собственные snapshots или переключение между ними; выбор привязки делает оркестратор.

## Как измеряется прогресс

Оценка выполняется на замороженном корпусе. Scorer сравнивает координаты ответа с ground truth по
геодезическому расстоянию WGS84; основной показатель — средняя ошибка, дополнительно фиксируются
медиана и число penalized samples. Положительная разница между baseline и memory-run означает
уменьшение ошибки.
