# AGENTS.md

Инструкции для агентов, работающих в этом репозитории.

## О проекте

Loci — фоновый агент геолокации по фотографии, накапливающий опыт между задачами. Суть, механика и обоснования решений — в бандле `docs/`, точка входа `docs/index.md`.

Стадия проектирования: кода пока нет, репозиторий содержит только документацию.

## Документация

- `docs/` — knowledge bundle в формате **OKF**: дерево markdown-файлов с YAML-frontmatter. Один файл — один концепт, обязательное поле `type`, рекомендуемые `title`, `description`, `timestamp`.
- **Добавил, удалил или переименовал концепт — обнови `index.md` своей директории в том же коммите.** Индексы обеспечивают прогрессивное раскрытие: читатель видит состав раздела, не открывая файлы.
- Перекрёстные ссылки — абсолютные от корня бандла: `[карточка урока](/concept/lesson-card.md)`.
- Файл `log.md` намеренно не ведётся: историю изменений даёт git.
- Перед коммитом изменений в `docs/` прогоняй валидатор:

```
python3 ~/.claude/plugins/cache/writer-assistant/plan/2.8.0/skills/okf/scripts/validate_okf.py docs
```

Допустим только результат `CONFORMANT` без ошибок.

## Решения

`docs/decisions/` фиксирует принятые решения **вместе с отвергнутыми альтернативами и причинами отказа**. Не переоткрывай эти споры без новых аргументов — выбор домена, метрики и источника данных обоснован и зафиксирован.

Решение со статусом «обсуждается» помечено в теле документа явно.

## Язык

- Документация, комментарии к решениям и сообщения коммитов — **русский**.
- Идентификаторы кода, имена файлов и полей — **английские**.
- Любой пользовательский текст, если он появится, — **английский (US)**.

## Данные

Снапшот изображений в git не хранится: он объёмный и восстанавливается по плану выгрузки. Access token Mapillary держится в `.env` и не коммитится ни при каких обстоятельствах.

Изображения Mapillary распространяются под CC BY-SA 4.0 — атрибуция автора собирается вместе с кадром на этапе выгрузки.
